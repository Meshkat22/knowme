A real-time BCI game built with the **Emotiv EpocX** headset and its **Cortex API**. The screen shows a tug-of-war, and the only way to pull the rope is with your mind: the game decodes left/right motor imagery from EEG and turns it into pulling force against the computer.

- Online decoding of left/right motor imagery, feeding the game state in real time
- Live signals from the EPOC X headset, no playback
- Built as a demo of how EEG decoding can drive something fun, not just plots

**Stack:** Python, Emotiv EpocX, Cortex API
